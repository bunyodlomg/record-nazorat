════════════════════════════════════════════════════════════════════
  MUAMMOLAR (TROUBLESHOOTING)
════════════════════════════════════════════════════════════════════

❌ "502 Bad Gateway"
   → Node server ishlamayapti.  pm2 status   |   pm2 logs recordnazorat-api
   → MongoDB ham tekshiring:  systemctl status mongod

❌ "Cannot GET /api/..."  yoki API javob bermayapti
   → Nginx config /api/ proxy_pass to'g'rimi:  /etc/nginx/sites-enabled/recordspeaking.uz
   → curl http://127.0.0.1:5000/health   (VPS ichida, direct Node)

❌ Login "401 Invalid email or password"
   → Demo seed bajarilmagan.   cd /var/www/recordnazorat/server && npm run seed
   → DIQQAT: seed butun bazani tozalaydi!

❌ Telegram WebApp ochilmaydi yoki "auth failed"
   → BotFather'da Mini App URL https://recordspeaking.uz ekanini tekshiring
   → server/.env'da WEBAPP_URL va BOT_TOKEN to'g'rimi
   → pm2 restart recordnazorat-api

❌ SSL muddati tugagan
   → certbot renew
   → Avtomatik bo'lishi kerak edi:  systemctl status certbot.timer

❌ "Permission denied" yoki "EACCES"
   → /var/www/recordnazorat egasini tekshiring:  ls -la /var/www
   → chown -R root:root /var/www/recordnazorat   (yoki o'z user'ingiz)

❌ Disk to'lib qoldi
   → pm2 logs juda kattalashgan:  pm2 flush
   → MongoDB log:  /var/log/mongodb/mongod.log    →    logrotate ulang
   → npm cache:  npm cache clean --force


════════════════════════════════════════════════════════════════════
  XAVFSIZLIK TAVSIYALARI
════════════════════════════════════════════════════════════════════

1) root o'rniga alohida sudo user yarating:
   adduser deploy
   usermod -aG sudo deploy
   # SSH key ni shu user'ga ham nusxalang, keyin root login'ni o'chiring:
   nano /etc/ssh/sshd_config   →   PermitRootLogin no
   systemctl restart ssh

2) fail2ban (SSH brute-force himoyasi):
   apt install -y fail2ban
   systemctl enable --now fail2ban

3) Avtomatik xavfsizlik yangilanishlari:
   apt install -y unattended-upgrades
   dpkg-reconfigure --priority=low unattended-upgrades

4) MongoDB tashqaridan ochiq EMASligini tekshiring:
   ss -tlnp | grep 27017
   # 127.0.0.1:27017 bo'lishi kerak (0.0.0.0 EMAS)

5) MongoDB backup (kunlik cron):
   mkdir -p /var/backups/mongo
   crontab -e
   # Quyidagi qatorni qo'shing (har kuni 03:00 da backup):
   0 3 * * * mongodump --db recordnazorat --out /var/backups/mongo/$(date +\%F) && find /var/backups/mongo -mtime +7 -exec rm -rf {} \;

6) .env va JWT_SECRET ni hech qachon GitHub'ga pushlamang.
   Tekshirish:  git ls-files | grep -E "\.env$"   →   bo'sh bo'lishi kerak
